# Sushant Kumar Portfolio — V1

A focused single-page portfolio for a 3-day launch.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS

## Requirements

- Node.js 20.19+ or 22.12+

## Run locally

```bash
npm install
npm run dev
```

Production checks:

```bash
npm run lint
npm run build
```
